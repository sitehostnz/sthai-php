# sthai-php

A PHP client for the [SiteHost AI Platform](https://kb.sitehost.nz/ai-platform): inference, embeddings and reranking, with no runtime dependencies beyond `ext-curl` and `ext-json`.

This is a port of the Python client, [sthai-py](https://github.com/ftsartek/sthai-py), matching its functionality and wire format.

**Work in progress** - not yet released.

## Requirements

- PHP 7.4 or newer
- `ext-curl`, `ext-json`
